# OviDrive — revised LinkedIn design set

September 2026 · Version 2

Six redesigned posts using the social-graphics workflow and the confirmed purple/cyan palette.

- New photographic fleet scenes for posts 1 and 4.
- Generated sculptural arrows for the procurement post.
- Open, light infographic layouts with sharper Inter / Inter Tight typography.
- Opposing light/dark layout for the two AI outcomes.
- Original OviDrive logo, with a white monochrome treatment on dark artwork.

## Files

PNG/ contains four 1200 × 1200 posts and two 1080 × 1350 infographics.
Editable/ contains SVG files with editable text, embedded fonts and raster artwork layers.
Captions/ contains the original supplied captions, unchanged.
Fonts/ contains the two font families and licences.
COPY-REVIEW.md records unresolved issues in the supplied copy.

The two photographic fleet scenes are AI-generated illustrations, not photographs of OviDrive customer sites. Sculpture imagery was generated with the built-in image generation tool. Captions and on-image copy remain unchanged; some text blocks were reordered to improve hierarchy.
